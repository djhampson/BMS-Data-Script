write a python script that read only data values from a DALY smart bms model K and updates a json dict named BMS_Data.  The DALY bms has a UART2 port that is connected via cable to a USB port of a raspberry pi 3B running debian and python.  The serial data format and message protocol is in the "modbus format" sheet of the attached spreadsheet.  Script initially opens a serial port then loops through a list of items whose key name is defined in the "content" column of the table in the "Real-time data" sheet of the attached spreadsheet, as well as the "address", "scope" and "data calculation instructions".  For each item, send a request frame to the DALY, read the response frame, extract the data using Length byte, then convert to decimal data using formulas derived from the "data calculation instructions" then validate using "scope" and update the BMS_Data dict.  When all items have been read pause for 1 second before repeating.
